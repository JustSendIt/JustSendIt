01

What this is

JustSendIt is a website built around two joke cryptocurrencies called $SEND and $GWC. A joke cryptocurrency, usually called a memecoin, is a coin made for fun and community rather than for solving a problem. Most of them lose all their value. That is not a warning buried in small print here; it is the starting assumption the whole site is designed around.

The site does four things. It explains how to buy the coins if you have never bought crypto before. It gives people a place to hang out, post, and follow each other. It runs a points game that rewards showing up and taking part. And it scans brand-new coins as they appear and flags the ones that look dangerous.

Here is the important part. The site never holds your money, never asks for your password to a wallet, and never tells you to buy anything. It is a scoreboard and a clubhouse, not a bank and not a broker.

The one-sentence version

A clubhouse for two joke coins, with a points game attached and a smoke detector pointed at new coins — where nothing you do can be paid for, and nothing the site says is advice.

The coins and the chain

A blockchain is a shared public notebook. Every transaction anyone makes is written in it, everyone can read it, and nobody can quietly erase a page. These coins live on one called Robinhood Chain. Every blockchain has an ID number so software knows which one it is talking to. This one is 4663.

Each coin is a small program living at a fixed address on that chain. An address is a long string starting with 0x. It is like a house number: it never changes, and anyone can look up what happens there.

03

What it refuses to say

Most crypto websites are adverts. This one is built with a short list of things it is not allowed to claim, and those rules show up in the code and the copy, not just in an about page.

  • It never says a coin will go up. It shows what the chain says and lets you decide.
  • It never claims to be unhackable. No site can honestly promise that, so it does not.
  • It is not connected to Robinhood the company. The chain is called Robinhood Chain. That is where the name comes from and nothing more.
  • It calls itself entertainment. Points, levels and games are for fun. They are not money and cannot be exchanged for money.
  • It never inflates a number. If the site cannot verify something, it says so instead of guessing.
Read this bit twice

Brand-new coins are dangerous by default. Most go to zero. The scanner in section 13 is a smoke detector, not a safety certificate, and a green score is never permission to buy.

04

Getting an account

You can join in three ways: with a crypto wallet, with an email and password, or through Google, Facebook, X or Instagram.

Signing in with a wallet

A wallet is an app that holds your coins. Signing in with one does not hand it over. The site shows you a sentence and asks your wallet to sign it, the way you might sign your name to prove it is you. Signing a sentence moves nothing and gives permission for nothing.

The sentence has the website's own address written inside it. That matters. If a scammer copies this site onto a lookalike domain, the sentence their fake site shows will name their address, so an alert reader can spot the mismatch before signing. The site also invents a fresh random code for each attempt, so an old signature cannot be reused later.

localhost:8642 wants you to sign in with your wallet. Read-only sign-in to JustSendIt. This signature never moves funds and grants no token approvals. URI: http://localhost:8642 Address: 0x… Chain ID: 4663 Nonce: <fresh random code> Issued At: <timestamp> Expiration Time: <10 minutes later>
The real message, as the server writes it. The domain, the chain, a single-use code and a ten-minute expiry are all inside the text you sign. Always check the first line names the site you are actually on.

Signing in with a password

Passwords are never stored. They are put through a slow scrambling process called scrypt, which is deliberately hard for a computer to run millions of times, so guessing is expensive. Only the scrambled result is kept. Passwords are also capped at 1024 characters so nobody can jam the server with an enormous one.

Two-factor

You can add a second lock. One option is a six-digit code from an authenticator app that changes every 30 seconds. The other is a wallet signature. Turning wallet two-factor off requires a fresh wallet signature, so someone who steals a logged-in session still cannot remove it. Code guessing is rate-limited and gives up after five tries, which destroys the half-finished login.

05

Scrambling your data

Everything personal is stored scrambled, using a method called AES-256-GCM. Think of it as a safe that also has a tamper seal: without the key you cannot read what is inside, and if anyone alters the contents the seal breaks and the site refuses to trust it.

The key lives outside the database. In a proper deployment it is set as an environment variable. On a developer's machine the server makes one and writes it to a file only the owner can read.

The clever bit: looking things up without unlocking them

If your email is scrambled, how does the site find your account when you log in? It keeps a second value called a blind index: a fixed fingerprint of your email made with a secret key. Two identical emails always make the same fingerprint, so the site can match you, but the fingerprint cannot be turned back into your email.

What a thief would actually see — stated precisely

Someone who copied the database without the key would find meaningless text starting with v1: where the emails, linked wallets and two-factor secrets should be. That much is genuinely protected.

But it is not true that the file would tell them nothing. Usernames, profiles, every post and comment, the follow and mute graph, each account's $SEND and $GWC balances, and the dollar amounts spent on calls are all stored in plain form, because most of it is public on the site anyway. Two places also record a wallet address in plain text next to an account: the record of a Send Call, and the log of points awarded.

So the honest summary is that the most sensitive fields are encrypted and the rest of the database is readable. And if the key were stolen along with the data, even the encrypted part would be open — which is why the key belongs somewhere the database backups are not.

06

Locking the doors

Web attacks mostly work by getting a browser to run code it should not, or by tricking your browser into doing something while you are logged in. The site closes those doors with rules the browser itself enforces.

The strict list

A Content Security Policy is a list the site hands your browser saying where code and images may come from. This one is unusually tight: scripts may only load from the site itself, and there is no inline script anywhere on any page. If an attacker somehow slipped a script tag into a post, the browser would refuse to run it.

default-src 'self' script-src 'self' ← only our own code, ever style-src 'self' 'unsafe-inline' fonts.googleapis.com img-src 'self' data: blob: cdn.dexscreener.com dd.dexscreener.com connect-src 'self' rpc.mainnet.chain.robinhood.com robinhoodchain.blockscout.com api.dexscreener.com frame-src dexscreener.com ← only price charts frame-ancestors 'none' ← nobody can hide us in their page object-src 'none'
The full policy. frame-ancestors 'none' stops a scammer loading the real site invisibly inside a fake one, an attack called clickjacking.

Checking who asked

Whenever something changes — a post, a call, a setting — the server checks which website the request came from and rejects it unless it came from this one. That stops another site from acting for you while you happen to be logged in.

Speed limits

Nearly every action has a cap on how often it can be repeated. Making Send Calls is limited to 10 attempts every 10 minutes, comments 25, joining communities 30, and starting a community 3 per day. Logins and wallet challenges are limited per IP address. The limits sit far above what a real person does and far below what a script needs.

Uploads

The site does not trust what a file calls itself. It reads the first few bytes of every upload and checks they match a real image or video. A file named cat.png that is secretly a program fails that check.

07

Your wallet stays yours

This is the part people worry about most, so here it is precisely.

The site never takes custody. It never sees a private key or a recovery phrase, it cannot move your coins, and it cannot approve anything on your behalf. Linking a wallet is a signature, which proves ownership and nothing else.

There is exactly one feature where real money moves, and it is the built-in swap. When you use it, the site builds a transaction and hands it to your wallet. You approve it, in your own wallet, and then your ETH really does leave. Nothing else on the site can spend anything.

Be precise about this

“Non-custodial” means the site cannot move your money on its own. It does not mean money never moves. The swap spends real ETH the moment you approve it in your wallet, and a swap that goes badly is still your loss.

How holdings are checked

Your rewards depend on what you actually hold, so the site never asks your browser. It reads your balance straight from the blockchain on the server, where you cannot edit the answer. A check is only trusted for 26 hours. After that your bonus pauses until it is re-checked, which happens automatically whenever you open your dashboard.

That pause is deliberate. Without it, someone could get verified once, sell everything, and keep the bonus forever.

The wallet tracker

You can save wallet addresses to watch what they do. These are read from public blockchain records, they are private to your account, and they are stored scrambled.

Send Power

Send Power is the points system. Almost everything useful earns some. Points are also experience, so earning them raises your level.

Two rules keep it fair. Nearly every action has a daily cap, so it cannot be repeated forever for points. And every award is recorded with a unique tag, so the same action can never be paid twice.

One exception, and one limit that stands in for it. A call’s milestones have no daily cap, because they are earned by a coin’s real performance rather than by repeating an action. But everything a single call ever pays its caller — the opening award, every milestone and the hold bonus together — comes out of one lifetime budget: the Send Power it takes to reach Level 70, about 737,000. No single payout may take more than a tenth of it. Someone who Sends It on your call has a budget of a quarter of yours. A great call is a big prize; it cannot be the whole game.

Multipliers

Base points are only the start. Four separate bonuses multiply together, and the result is what you are actually paid.

what you earn = base points × Holder Boost × OG bonus × Community bonus × Arcade boost
All four multiply. Someone with none of them earns exactly the base amount, because each bonus is 1× when it does not apply.

Holder Boost — owning the coins

The more of the coin supply you hold, the bigger your bonus. Every weighted 1% of supply adds 10. $GWC counts three times as much as $SEND for the same percentage.

That number is then multiplied by your Diamond level, which rewards holding without selling. Selling resets the streak to zero.

OG — being early

If you bought both coins and you still hold both, you earn an OG badge and a bonus on everything. There is one standard for everybody — the only thing that changes the size of the bonus is when you got in:

  • Gold — 10×. You bought both inside the first month.
  • Silver — 5×. You bought both in the two months after the gold window closed.
  • Bronze — 3×. You bought both in the nine months after the silver window closed.

After that the windows are shut and no badge is given, whatever you buy. Twelve 30-day months in total, counted from each coin’s own launch. Your tier is the lower of your two coins, because the rule is that you held both.

Two things also disqualify a wallet, and they apply the same way in every window. If it dumped its whole holding to nothing inside its first month and it is not a net accumulator — meaning it holds less today than it did at the end of that first month — it does not earn a badge. A wallet that sold out but bought back past where it started keeps its place.

All of this is read from the blockchain, and the check is refused rather than guessed if the data cannot be read completely. Sell out of either coin entirely, at any time, and the badge is revoked for good.

Community — taking part

Being a verified holder in at least one live community is a flat 10×. It is not per community. Joining five communities does not give you fifty times anything.

Arcade — today's game

Cashing out of Rocket Run gives a bonus of up to 5× lasting 24 hours. Section 12 explains it.

Why a bonus can switch off

Every holding-based bonus depends on a blockchain check no older than 26 hours. If yours goes stale, the bonus drops to 1× until it is re-checked. It is not a punishment; it is the only way to be sure you still hold what you claimed.

10

Send Calls

A Send Call is a public prediction. You pick a coin, and a permanent scorecard appears on your wall tracking how it does from that moment on. It is a way of putting your reputation where your mouth is.

A call can never be edited or deleted. That is the whole point. A prediction you can delete after it goes wrong is worthless. Its best-ever result is kept forever, even if the coin later dies.

How results are counted

Results are counted in Xs. Doubling in price is 1X. Going up 340% is 3.4X. Every whole X pays 180 × that X, so hitting 1X pays 180, hitting 3X pays 540, and the ladder stops at 50X.

Holding is the main event

The ladder is the smaller prize. While a call stays in profit it keeps earning a diamond-hands hold bonus that grows faster than the Xs alone — higher and longer both count, and they compound. Every call has one lifetime budget (Section 8), and it is carved on purpose: the opening award may take at most a tenth of it, the ladder at most three tenths, and at least six tenths are reserved for holding in profit. Cash a coin at 50X and walk away and you leave most of the budget on the table.

It also pays more when you are not alone. When the people who tapped Send It on your call are themselves in profit from their own entry, your hold bonus accrues faster: one tenth extra per profitable hopper, up to three times the base rate. A conviction play that carries other people with it is worth more than a lonely one, and the only way to earn that is to stay in profit long enough for them to be too.

The scale runs E to S. The code also defines an F for “underwater”, but a Send Call can never receive it: a call's score is measured against its highest point ever reached, which starts at the entry price and only ever moves up. A call that falls below where it started scores E, not F.

Rules that stop cheating

  • A coin needs at least $500 of trading liquidity to be callable. Otherwise someone could create a fake coin, trade with themselves, and farm a huge score.
  • You get 5 calls a day to start, counted over a rolling 24 hours so midnight is not a reset to abuse. A day where one of your matured calls doubled earns you an extra slot, up to 5. A day where they all flopped costs you one, down to a floor of 1.
  • A call is only judged after 24 hours, so it gets a fair chance to run.
  • If a coin you called gets rugged — its liquidity pulled by the creator — your daily allowance drops by 2.
  • Burning a full day's allowance inside one hour is treated as spam, and only counts if your allowance was 3 or more, so a one-call-a-day user is never punished for using it.

Other people can tap Send It on your call to join in. They earn from their own entry price, not yours, and it is capped at 30 a day.

11

Communities

Any coin can have a community. You paste its address, and if it has at least $500 of liquidity a page is created, automatically decorated with the coin's logo and links.

A community stays in starting-up mode until 10 verified holders have joined. Only then does it go live.

Proving you belong

To count as verified you must actually hold that community's own coin, checked on the blockchain from a wallet you signed with. This is re-checked in the background. Sell your coins and you lose your verified status and the 10× with it.

Two rules stop one person pretending to be a crowd. No more than 2 verified joins may come from the same network address, and joins from the founder's own network do not count toward their own community going live.

There is one exception to holding: the wallet that created the coin can start its community without holding any, because the chain already proves who they are.

Community XP and conviction

Communities level up from what their members do inside them. Members separately earn conviction, which is personal loyalty to that one community.

Caps stop one loud person carrying a community: a single member can push at most 250 community XP per day into any one community, and earn at most 150 conviction there per day.

The weekly competition

Each week the communities are ranked by points earned that week alone. The week runs Monday to Monday in UTC and every score resets to zero at the rollover. All-time community level is untouched.

The ranking measures activity only. Price, market value and holder count count for nothing. There is no prize.

12

Rocket Run

A free game, once per day. A rocket climbs and a number rises with it. You tap to cash out whenever you like. At some hidden moment the rocket explodes, and if you have not cashed out by then you get nothing.

Nothing is at stake. There is nothing to buy, no way to pay to play again, and no way to lose anything you had. The only thing you can win is a temporary points bonus.

multiplier after s seconds = e ^ (0.06 × s) 10 seconds → 1.8× 30 seconds → 6× 60 seconds → 36× boost earned = 1 + (cash-out − 1) / 4 capped at 5× cash out at 2× → 1.25× boost cash out at 9× → 3× boost cash out at 17× → 5× boost (the cap)
The climb starts slow and accelerates. The reward for waiting is deliberately gentle, so waiting longer is mostly extra risk for very little extra bonus.

Why you cannot cheat, and neither can the site

This is the part worth understanding. When you launch, the server rolls the explosion point immediately and writes it down before you see anything. It is never sent to your browser until the round is over. Your browser is only drawing an animation; it genuinely does not know the answer.

Because the number was fixed at launch and stored, the site cannot move it either when it sees you about to win. And because the multiplier is calculated from the server's own clock, changing your computer's clock does nothing.

The honest limits of that

This makes cheating impossible for players and stops the outcome being changed mid-round. It is not the same as being mathematically provable to an outsider: you are trusting that the server rolled fairly. Since nothing is staked, there is nothing to win by cheating — but it is worth stating plainly rather than calling it provably fair.

Other rules: the explosion point is capped at 50×, a round left abandoned expires after 5 minutes and counts as a loss, and the day rolls over at midnight UTC.

The daily check-in

Showing up is worth 20 points, once per day, claimed by tapping a button on your own wall. It used to happen silently on page load. Making it a button means it is something you did, not something that happened to you.

The risk scanner

New coins appear on Robinhood Chain constantly, and a lot of them are traps. The New Pairs Radar watches them appear and puts a plain-English warning label on the dangerous ones.

Every coin starts at 100 out of 100. Each warning sign that trips subtracts points.

The score sorts coins into bands, and the radar has three views: Best Runners for biggest gainers, the Hot Feed for the highest-scoring new coins one at a time, and the DEX List with every filter. A coin whose name and symbol cannot be read from the chain is hidden from all three, because a coin nobody can identify is not something to show anyone.

An important weakness, stated openly

A warning can only trip on data the site could actually read. If a coin is so new that its liquidity, holder and verification data have not been indexed yet, nothing trips, and it scores 100 out of 100 — the same score as a coin that genuinely passed every check. A perfect score can mean “all clear” or it can mean “we could not see anything”, and today the display does not distinguish them. Treat a 100 on a very fresh coin as unknown, not as safe.

The data comes from three public sources: the chain's own node, a block explorer, and a price service. The score is a set of quick heuristics on public data. It is not an audit, not a guarantee, and not advice.

Posting and muting

There is a shared feed called the Send Wall, and everyone gets a public page of their own. You can post text, images, GIFs and video, comment, react, vote, follow people and search for them.

If you paste a coin's address into a post, the site quietly replaces it with the coin's ticker, which anyone can tap to see its full details. Up to three addresses per post are converted this way.

Muting

On anyone's public profile there is a Moderation menu with a mute option. Muting is one-sided and private. Their posts and comments disappear from your feeds. Where they cannot be removed entirely, such as inside a list of people on a call, they appear greyed with a muted marker you can tap to unmute.

15

The bot catcher

A points game invites scripts. The site watches how fast accounts create things and whether they post the same thing repeatedly. Accounts acting faster than a human is capable of are put into read-only mode.

Read-only is not a ban. You can still browse everything, check in daily, connect a wallet, buy and hold coins, and keep earning from your Holder Boost. What stops is creating things: posting, commenting, reacting, voting, following, calling, and customising.

The punishment escalates: 24 hours the first time, one week if it happens again, and permanent after that. The thresholds are set far above ordinary enthusiastic use.

One design choice you should judge for yourself

A restriction can be lifted early by buying and holding $SEND: $25 worth per 24 hours of the restriction, or a flat $1,000 to clear a permanent one, which must then be held for 40 days. The money goes into the coin, not to the site, and the coins stay yours. It is still a mechanic where spending money removes a penalty, and anyone reading this should weigh that for themselves rather than take our framing for it.

16

How it is built

The site is deliberately simple. There is no framework, no build step and no bundler. It is plain JavaScript that runs in the browser exactly as written, and a single Node.js program on the server.

  • One server file holds every rule. Having one source of truth means the number you see and the number you are paid cannot drift apart.
  • SQLite stores everything in a single file on disk.
  • No JavaScript is written inline in any page, which is what allows the strict security policy in section 6.
  • Only two outside code libraries are used: one for checking wallet signatures, one for drawing QR codes.

The advantage of this style is that anyone can read it. There is no compilation between what is written and what runs, so the code in the repository is the code in your browser. For a project asking people to trust it, that is worth more than convenience.

17

Honest limits

A white paper that only lists strengths is an advert. These are the real limits.

  • A perfect risk score can mean “no data”. Described in section 13. It is the most important caveat on the page.
  • The site depends on outside services. Prices, holder counts and contract details come from a price service and a block explorer. If those are wrong or offline, the site shows less, and it says so rather than inventing numbers.
  • Encryption protects a stolen database, not a stolen server. If an attacker took the key as well as the data, the scrambling would not save you.
  • Rocket Run is fair but not provably fair. You are trusting the server's roll. Nothing is staked, so nothing is lost either way.
  • Points are not money. They cannot be cashed out, sold or transferred, and they never will be.
  • Nothing here is advice. The site shows what the blockchain says. What you do about it is yours to decide, and most new coins go to zero.
The point of all this

Crypto is full of sites that promise safety and deliver marketing. This one tries the opposite: state the rules exactly, show the real numbers, admit what it cannot see, and never tell you what to buy. Whether that is enough is for you to judge — which is the whole idea.
